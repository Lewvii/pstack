# 先减后加

演进一个系统时，先去掉复杂度，再往上构建。默认选择减法。

把简化当成持续的投资。交出去的应当是：暴露面不变或更小，而设计略微更简单、能力更强。

- 删除排在构建之前
- 先砍再打磨（先到最小，再投入质量）
- 按观察到的用法来设计，不按臆想的边界情况
- 规范没要求的校验器、解析器、守卫，一律不要加
- 简化提示词（去掉冗余指令和过多的模板）
- 某个引用已经没有新内容时，删掉它，而不是留一个占位
